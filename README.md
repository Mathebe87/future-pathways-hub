# Future Pathways Hub

## Project Overview

Future Pathways Hub is a web-based platform designed to help students explore educational and career opportunities. The system provides a centralised platform where users can access university-related information, career opportunities and other student-focused services.

## MVP Features

The Sprint 5–6 MVP includes:

- User registration and authentication
- Student profile management
- University and study-related information
- Career and job opportunities
- Application functionality
- Role-based system functionality
- Integration with backend services and Supabase

## Technology Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS

### Backend / Services
- Supabase
- PostgreSQL
- Supabase Authentication
- Supabase Storage

### Deployment

- Frontend: Vercel
- Backend: Railway

## Prerequisites

Before running the project locally, install:

- Node.js
- npm

## Installation

Clone the repository:

git clone https://github.com/Mathebe87/future-pathways-hub.git

Navigate into the project:

cd future-pathways-hub

Install dependencies:

npm install

Create a `.env` file using `.env.example` and provide the required environment variables.

Start the development server:

npm run dev

The application will then be available through the local development URL displayed in the terminal.

## Environment Variables

Required environment variables are documented in `.env.example`.

Do not commit passwords, API keys, access tokens or other sensitive credentials to the repository.

## Deployment

The frontend MVP is deployed using Vercel and the backend API is deployed using Railway.
